从零搭一个微信小程序：技术选型回顾

一个周末小项目——接入 DeepSeek 的八字命理 Demo。6 个页面，7 个自定义组件，暗黑鎏金风格。总耗时约 10 小时。

小程序前端DeepSeek

项目概述

这是一个八字命理小程序 Demo。前端用微信原生框架开发——6 个页面覆盖命盘展示、人生树、智库、能量四个 Tab，加一个 onboarding 流程。后端接入 DeepSeek API 处理命理分析逻辑。

状态预计算

WXML 的数据绑定能力有限——不能在模板里调函数。所以在 JS 层做了大量预计算：农历转换、五行推算、命盘数据——全部在 setData 之前算好，模板只负责渲染。这样做虽然 JS 文件长了，但模板干净、渲染快、不会出现"算到一半卡住"的问题。

暗黑鎏金风格

视觉方向是暗色底+金色点缀——不是那种霓虹赛博暗黑，而是偏传统命理感的鎏金暖暗。深棕黑底色，金色文字和边框，朱红作为强调色。所有颜色用 CSS 变量统一管理，换肤只需要改几个值。

农历计算的坑

八字排盘需要精确的农历日期，但 JavaScript 没有原生农历支持。最终用春节表+LUNAR_INFO 位表实现了纯前端农历转换，不依赖任何后端接口。缺点是代码量大，优点是离线可用、零延迟。
